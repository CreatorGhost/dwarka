# Chapter 1 asset ledger

Every imported third-party asset has a recorded source and licence. Raw source archives are retained for audit; the browser export contains only Chapter 1 runtime selections. Static scenery and props were converted to GLB, deduplicated, pruned, and capped at 512 px WebP textures with `@gltf-transform/cli` 4.5.0. The player composite keeps a 1024 px cap and NPC composites use 512 px. Each character contains one 65-bone animation skeleton shared by face, eyes, hair, outfit, hands, and feet, preventing the detached-head and duplicate-torso failures from the earlier runtime assembly.

## Voice assets

Fixed Chapter 0 narration and Chapter 1 dialogue were generated with Sarvam `bulbul:v3` on 2026-09-02 and validated with Sarvam `saaras:v3`. On 2026-09-04, the five-locale Vrishaketu mission line `ch1-opening-mission` was generated with the same `aditya` persona and validation pipeline. The cache contains 65 line-locale entries and 130 files, one MP3 and one OGG for every entry, under `site/public/audio/chapter-1/voices/`. The locale-aware manifest is `site/public/audio/chapter-1/voice-manifest.json`.

The narrator audition set under `site/public/audio/auditions/` contains one English and one native-script Hindi OGG for each of the 37 documented Sarvam `bulbul:v3` speakers, plus a local static comparison page. These synthetic, throwaway evaluation clips use the exact `ch0-panel-01-battlefield` copy and are intentionally excluded from the shipped voice manifest. Sarvam provider terms apply.

The manifest records provider, model, synthetic status, locale, role, stable persona ID, source line ID, generation date, runtime path, file size, SHA-256 checksum, and script-aware transcription validation. The Sarvam credential is read only from `VOICE_PROVIDER_API_KEY` or the user-authorized local credential CSV. It is never copied into the manifest, ledger, browser export, storage, logs, or screenshots. Release credits must identify these files as synthetic voices and note that Sarvam provider terms apply.
